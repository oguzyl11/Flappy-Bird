# Flappy Bird Game

Modern ve geliştirilmiş özelliklere sahip bir Flappy Bird oyunu. Python ve Pygame kullanılarak geliştirilmiştir.

## Özellikler

- Başlangıç ekranı
- Geniş görüş alanı
- Dinamik zorluk seviyesi
- Yüksek skor sistemi
- Gerçekçi kartal tasarımı
- Kademeli hızlanma sistemi

## Gereksinimler

- Python 3.x
- Pygame 2.5.2

## Kurulum

1. Repoyu klonlayın:
```bash
git clone https://github.com/oguzyl11/Flappy-Bird.git
cd Flappy-Bird
```

2. Gerekli kütüphaneyi yükleyin:
```bash
pip install -r requirements.txt
```

3. Oyunu başlatın:
```bash
python flappy_bird.py
```

## Nasıl Oynanır?

- Oyunu başlatmak için SPACE tuşuna basın
- Kuşu zıplatmak için SPACE tuşunu kullanın
- Borulardan geçerek puan kazanın
- Boruların arasından geçtikçe hız artar ve zorluk seviyesi yükselir
- Yüksek skoru geçmeye çalışın!

## Oyun Özellikleri

- **Otomatik İlerleme**: Kuş otomatik olarak ilerler
- **Dinamik Zorluk**: Her boru geçişinde:
  - Hız artar
  - Boru aralıkları daralır
- **Skor Sistemi**: 
  - Her boru geçişinde +1 puan
  - Yüksek skor kaydı
- **Gelişmiş Grafik**: 
  - Kartal benzeri kuş tasarımı
  - Hareketli kanatlar
  - Geniş oyun alanı
